# Interview Preparation — Enterprise Sales Analytics

## 30-second explanation

I created a sales and profitability analytics project using Excel. I started with transactional sales data, cleaned it by checking duplicates and data quality, calculated KPIs such as revenue, COGS, profit and profit margin, analyzed performance by year, category, region and product, and created a dashboard to communicate the results clearly.

## What is a Pivot Table?

A Pivot Table is an Excel feature used to quickly summarize and analyze large datasets by grouping fields and calculating values such as SUM, COUNT or AVERAGE.

### Pivot areas

- Rows
- Columns
- Values
- Filters

Example: Revenue by category

```text
Rows   → Category
Values → Revenue (Sum)
```

## Project questions

### Why did you clean the data?
Duplicate or invalid records can distort KPIs and lead to incorrect conclusions.

### Why calculate profit margin?
Profit margin measures profitability relative to revenue, making it easier to compare areas of different sizes.

### Why create a dashboard?
A dashboard presents important KPIs and trends in a format that business users can understand quickly.

### What was your challenge?
One challenge was making sure duplicate transactions did not distort the results. I checked the unique Order_ID field and removed the duplicate before calculating KPIs.

### What would you improve?
I would add MoM/YoY growth, customer segmentation, discount-vs-margin analysis and a Power BI version.
